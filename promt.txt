2. THE PROBLEM I'M SOLVING
================================================================================

The current admin dashboard looks "very traditional" — it reads like a 2018
admin panel: a navy sidebar (`#0D2B36`) with flat menu items, a plain white
topbar, a basic user-menu dropdown, and a couple of cards. It does not feel
premium. It does not feel "Cal­dan". I want the dashboard to give LIGHT-MODE
VIBES while still using the Caldan brand palette. I want it to look modern,
clean, iconic, and obviously engineered — something a creative director would
call "premium tier". Concretely:

- The whole canvas (sidebar, topbar, content, dropdowns) should feel airy,
  bright, and tactile in light mode. Dark mode is allowed (toggle exists) but
  the DEFAULT state we are designing FOR is light mode.
- Brand colours must remain identifiable. We are not repainting the company;
  we are restyling its admin surface in a premium light-mode treatment that
  still uses Royal Blue / Gold / Deep Navy as the chromatic anchors.
- Hover effects must be a DELIBERATE design system, not a `background: gray`
  fallback. Sidebar items, topbar buttons, dropdown rows, cards, and
  action tiles all need considered, layered, springy or eased hover states.
- The sidebar at the bottom and the topbar user dropdown at the top both
  need a PROFILE BANNER — a small card with avatar, name, role chip, and a
  one-line bio or status. Iconic, not utilitarian.
- ICONS: Font Awesome ONLY. No emoji (☀️, 🌙, 💻, 📦, etc.) anywhere. The
  current `appearance.html` uses ☀️ / 🌙 / 💻 inside `.theme-option` blocks —
  these MUST be replaced with `<i class="fas fa-sun">` / `fa-moon` /
  `fa-laptop` (or similar Font Awesome solid icons). Audit the entire
  dashboard for stray emoji and replace them.

4. THE SIX PILLARS OF THE REDESIGN
================================================================================

(1) LIGHT-MODE PREMIUM CANVAS
- Page bg #FAFBFC, cards #FFFFFF, very soft shadows.
- Replace harsh `box-shadow: 0 1px 2px rgba(0,0,0,0.05)` with a layered shadow:
  `0 1px 2px rgba(15,23,42,0.04), 0 8px 24px -12px rgba(15,23,42,0.08)`.
- Cards: 14px radius, 1px #ECEFF3 border, gentle hover lift (translateY(-3px)
  + shadow intensifies + 1px border becomes #D4AF37 with 35% alpha).
- Topbar: glass effect, 18px backdrop blur, 1px bottom border #ECEFF3, 72px
  height. Sticky with a soft shadow that appears only after 8px of scroll
  (use IntersectionObserver or a scroll listener — implement lightly).

(2) ICONIC HOVER SYSTEM
A single, opinionated set of hover recipes, applied to EVERY interactive
element. Pick a vocabulary and apply it consistently:

- Buttons (primary): bg shifts to --accent-primary-hover, translateY(-2px),
  shadow lifts to `0 12px 24px -8px rgba(11,102,195,0.35)`, icon does a
  4px translateX or a 6° rotate (one or the other, not both).
- Buttons (gold): same lift, shadow uses gold tint `rgba(212,175,55,0.35)`.
- Sidebar items: see "Sidebar treatment" above.
- Topbar icon buttons (search, theme, notification, user): 8px padding,
  10px radius, default bg transparent. Hover bg rgba(11,102,195,0.06),
  icon colour shifts to --accent-primary, scale 1.04.
- Cards: lift 3px, border tint, soft inner glow `inset 0 1px 0 rgba(255,255,255,0.6)`.
- Dropdown rows: 4px translateX, 2px left-border marker in gold fades in
  (0% to 100% width over 180ms), bg shifts to rgba(11,102,195,0.04).
- Quick-action tiles: tilt slightly (`rotate(-1deg)` on hover), icon scales
  1.15, bg gradient sweep from left-to-right in 320ms.
- Links: underline expands from left (width 0 -> 100% over 220ms).

(3) SIDEBAR PROFILE BANNER (at the bottom of the sidebar)
Currently the sidebar footer only has a version chip and a theme toggle. Add
a profile banner card above the footer (push the existing footer BELOW it
or fold the version chip into the banner footer). The banner should contain:

- 64px circular avatar (use the existing
  `{{ request.user.full_name|default:request.user.email|first|upper }}`
  fallback — but if `request.user.profile.avatar` exists, use that URL).
- Two-line name + role chip (gold pill: "Platform Admin" / "Chief Admin").
- One-line status: a small green dot + "Online" OR a custom status if
  `request.user.profile.status` exists (default to "Online").
- Three small icon actions inline (do NOT use emojis): envelope (mailto:
  `{{ user.email }}`), gear (link to appearance), and a chevron that expands
  a tiny "Sign out" link on hover.
- The whole card sits on a translucent white surface (rgba(255,255,255,0.04))
  with a 1px rgba(255,255,255,0.08) border, 12px radius, 16px padding.
- On hover: the card lifts 2px, the border brightens to rgba(212,175,55,0.45),
  the chevron rotates 90°.

This profile banner replaces the current `.sidebar-footer` block. The
theme toggle button can be moved into the banner as one of the three
inline icon actions OR kept below as a single discrete icon. Pick the
cleaner option and justify in a code comment.

(4) TOPBAR USER DROPDOWN (iconic)
Currently the user dropdown is a 280px plain card with header + 5 menu rows.
Redesign it to feel iconic:

- Width 320px, 16px radius, layered shadow, 1px border #ECEFF3.
- TOP STRIP: a small gradient banner (16px tall, Royal Blue -> Gold) with
  no text, just a decorative sheen. Sits inside the dropdown.
- HEADER (below the strip): 56px avatar + name (15px, weight 600) + email
  (12px, text-secondary) + role chip (gold pill, 11px uppercase).
- A "PRO" badge OR a small "Profile completion 80%" progress bar in the
  header — pick one and document. Use the JetBrains Mono for the percentage.
- MENU ROWS: each row is 44px tall, 12px horizontal padding, 12px radius on
  hover, icon in a 28px tinted square (tint = 8% of --accent-primary, icon
  colour = --accent-primary), label 14px, optional 12px shortcut hint on
  the right (e.g. `⌘P`, `⌘,`). Dividers: 1px #F1F5F9 with 12px horizontal
  inset.
- LOGOUT ROW: red tint, icon in a red 8% square, label in --accent-danger,
  a tiny "Securely sign out" caption underneath the label in 11px grey.
- The dropdown opens with a 220ms cubic-bezier(0.16, 1, 0.3, 1) slide+fade
  (translateY(-8px) scale(0.98) -> translateY(0) scale(1)).
- A small triangle pointer at the top of the dropdown (10px wide, white,
  rotated 45°, with a 1px top+left border #ECEFF3 to match the card).

(5) ICON SYSTEM (Font Awesome ONLY)
- All icons: `fas` (solid) for UI, `far` (regular) for secondary.
- Replace any `☀️` `🌙` `💻` `📦` `🔔` `✓` `🛒` `💼` etc. with Font Awesome.
  The audit MUST include:

- Icon sizing standard: 14px (xs) / 16px (sm) / 18px (md) / 20px (lg) /
  24px (xl). Container squares: 28/32/36/40/48. Icon must be vertically

(6) MICRO-INTERACTIONS & MOTION
- All transitions: cubic-bezier(0.16, 1, 0.3, 1) for "spring" or
  cubic-bezier(0.4, 0, 0.2, 1) for "standard". 180-260ms typical.
- Dropdown open/close: 220ms slide+fade.
- Sidebar item active: pill slides 4px from the right via transform.
- Topbar icon buttons: scale 1 -> 1.04 on hover, scale 0.96 on active.
- Notification badge count: a tiny pop animation (scale 0.6 -> 1.1 -> 1)
  on count change.
- Theme switch: cross-fade the body 220ms via opacity, not a flash.
- Respect `prefers-reduced-motion: reduce` — disable transforms and use
  opacity-only transitions, and remove the pop animation.
